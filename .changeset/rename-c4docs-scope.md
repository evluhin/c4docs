The toolchain is now published under the `@c4docs` npm scope. Install `@c4docs/likec4` instead of `likec4`, and depend on the scoped package names (for example `@c4docs/likec4-core`, `@c4docs/likec4-diagram`, `@c4docs/likec4-react`). The CLI command remains `likec4`.
